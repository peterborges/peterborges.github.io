GovWell Plan Review

Modernizing the plan review process for local governments

Role

  • UX Designer
  • UI Designer
  • Prototyping

📅 Timeline

2025

The Challenge

Local governments struggle with outdated, paper-based plan review processes that are time-consuming, error-prone, and lack transparency. Reviewers and applicants need a modern, digital solution that streamlines workflows, improves communication, and provides clear visibility into the review status.

Key Problems

"We're drowning in paper. Tracking which version of plans we're reviewing and what changed between submissions is nearly impossible." — Plan Reviewer
"The tools we have are so rigid. Once I place a stamp or markup, I can't adjust it. I end up starting over multiple times just to get the placement right." — Building Inspector
"There's no visibility into where plans are in the review process. Applicants call constantly asking for status updates, and we waste time tracking down information manually." — Planning Department Manager

The Solution

GovWell Plan Review is a comprehensive digital platform that replaces outdated, paper-based processes with a streamlined, transparent system. The solution enables reviewers to efficiently manage submissions, collaborate with stakeholders, and track progress through every stage of the review cycle.

Key Features

01 Plan Version Comparison

I designed side-by-side and overlay comparison tools that allow reviewers to instantly identify changes between plan submissions. A "Modified" badge automatically appears next to any documents that differ from the previous version, eliminating the time-consuming task of manually comparing plans.

This feature addresses the critical pain point of tracking version changes, enabling reviewers to focus their attention on what actually changed rather than spending hours cross-referencing documents.

02 Flexible Plan Review Toolkit

I reimagined the Plan Review Toolkit based on user feedback, transforming rigid markup tools into a flexible system where stamps and annotations can be freely moved and edited directly within plan reviews.

Reviewers can now adjust placements without starting over, reducing frustration and significantly decreasing the time spent on each review. Frequently used tools are positioned prominently, while advanced options remain accessible but don't clutter the primary workspace.

03 Digital Submission Portal

I created an intuitive online interface that enables applicants to submit plans and documents digitally, replacing paper-based processes. The portal guides users through the submission process with clear instructions and validation.

The system automatically organizes submissions and provides immediate confirmation, giving applicants confidence that their materials have been received and are in the review queue.

04 Review Dashboard

I designed a centralized workspace that allows reviewers to manage multiple projects simultaneously and track status across all active reviews. The dashboard provides at-a-glance visibility into workload, priorities, and deadlines.

Key information is positioned above the fold, with filtering and sorting capabilities that enable reviewers to quickly find the projects they need to work on. Less frequently accessed controls are organized in secondary sections to maintain a clean, focused interface.

05 Advanced Stamps System

I developed a comprehensive stamping system with extensive customization options including border, opacity, and color controls. Reviewers can add text, dates, and signatures to stamps, with background removal capabilities for image-based stamps.

The shared stamps feature allows teams to create and distribute standardized stamps across staff members and modules, ensuring consistency and reducing setup time for new reviewers.

06 Plan Set Revisions

I designed a revision workflow that allows approved plan sets to be updated anytime without disrupting ongoing processes. Revisions can be initiated directly within the same plan set and work in parallel with other workflow steps.

This eliminates the need to restart the entire review process when changes are required, allowing projects to move forward without delays while revisions are processed simultaneously.

Design

The interface was designed from the ground up to provide a clean, intuitive experience that guides users through the review process with clarity and efficiency.

Impact

  • Reduced review cycle time by streamlining workflows and eliminating manual processes
  • Improved transparency and communication between applicants and reviewers
  • Enhanced data accuracy through digital validation and error prevention
  • Increased user satisfaction with an intuitive, modern interface

Plan Review Toolkit

Based on user feedback, the Plan Review Toolkit was completely reimagined to address usability concerns and provide a more consistent experience. The toolkit allows reviewers to freely move stamps and edit markups directly within plan reviews, eliminating the frustration of rigid tools and enabling more flexible review workflows.
